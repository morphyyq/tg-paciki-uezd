# Бесплатный Telegram-бот ежедневного счётчика

Этот вариант работает через GitHub Actions и не требует платного Render. Каждый день в 15:00 по московскому времени бот публикует в Telegram:

> С уезда пацанов прошел 1 день

Первый день: **31 августа 2026 года**.

## Важно про токен

Токен, опубликованный в чате, нужно отозвать через `@BotFather`: команда `/revoke`, затем новый токен через `/token`. Настоящий токен нельзя помещать в код или обычные файлы репозитория.

## 1. Добавь бота в канал

1. Открой канал.
2. Зайди в **Управление каналом → Администраторы → Добавить администратора**.
3. Выбери бота и включи право **Публиковать сообщения**.
4. Если канал публичный, его username можно использовать напрямую, например `@my_channel`.

## 2. Создай GitHub-репозиторий

Загрузи файлы проекта, включая папку `.github/workflows/daily.yml`. Репозиторий можно сделать публичным, тогда GitHub Actions для такого небольшого задания не требует оплаты. Токен всё равно добавляй только как Secret.

## 3. Добавь секреты GitHub

В репозитории открой:

**Settings → Secrets and variables → Actions → New repository secret**

Создай два секрета:

```text
TELEGRAM_BOT_TOKEN = новый токен от BotFather
TELEGRAM_CHAT_ID = @username_канала
```

Для публичного канала можно указать `@username_канала`, числовой ID не нужен.

## 4. Запусти первый день сегодня

Открой вкладку **Actions**, выбери workflow **Daily Telegram counter**, нажми **Run workflow** и подтверди запуск. Бот отправит сегодняшнее сообщение с числом `1`.

После этого workflow будет запускаться автоматически каждый день в 15:00 по Москве.

## Важные ограничения

GitHub предупреждает, что scheduled workflows могут запускаться с задержкой при высокой нагрузке. Для обычного ежедневного сообщения это обычно приемлемо. Workflow запускается только из файла, который уже находится в основной ветке репозитория.
